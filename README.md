# Taller .NET

Enfocado principalmente en el desarrollo web con **ASP.NET Core** y una introducción al desarrollo de aplicaciones distribuidas (microservicios) con **.NET Aspire**. 

---

## Tecnologías que veré
### Framework Web

* **ASP.NET Core Web API**
  Desarrollo de APIs REST y servicios backend.

* **ASP.NET Core MVC Web App**
  Desarrollo de aplicaciones web dinámicas renderizadas en el servidor utilizando MVC y Razor.

* **Blazor Server**
  Desarrollo de aplicaciones web interactivas cuya lógica se ejecuta principalmente en el servidor.

* **Blazor WebAssembly**
  Desarrollo de Single Page Applications (SPA) que se ejecutan directamente en el navegador mediante WebAssembly.

---

### Aplicaciones distribuidas

**.NET Aspire**.
Orientada al desarrollo y gestión de aplicaciones distribuidas, incluyendo escenarios basados en arquitecturas de microservicios.
